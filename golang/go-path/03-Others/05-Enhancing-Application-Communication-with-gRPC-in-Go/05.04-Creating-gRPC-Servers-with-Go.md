# 05.04 Creating gRPC Servers with Go

> **Go Path - Zero to Gopher** / **03 Others → Enhancing Application Communication with gRPC in Go** / Lesson 05.04

## Lesson goals

After this lesson you should be able to:

- implement the generated server `interface`
- embed `Unimplemented*Server`
- register the service on `grpc.Server`
- return `status` errors
- do `GracefulStop`
- test with `bufconn` without a real TCP port

## Prerequisite

- 05.03 (`make generate` works)
- generated `*_grpc.pb.go`
- 05.02 glossary (status, ctx, interceptor)

## Problem this lesson solves

People bring HTTP mux habits to gRPC and forget the Unimplemented embed, GracefulStop, passing `ctx`, and synchronizing in-memory state. Polyglot clients then see `Unknown` / `Unimplemented` and blame “proto”.

## Mental model

```text
your struct
  embed UnimplementedCatalogServer (or Inventory)
  implements SayHello / GetStock / ...
       ↓
Register*Server(grpc.Server, impl)
       ↓
net.Listen + Serve
       ↓
HTTP/2 dispatch → your method
```

## Mechanism

### Inventory unary (short lab)

```go
type server struct {
	pb.UnimplementedInventoryServer
	mu    sync.Mutex
	stock map[string]int32
}

func (s *server) GetStock(ctx context.Context, req *pb.GetStockRequest) (*pb.GetStockResponse, error) {
	if err := ctx.Err(); err != nil {
		return nil, status.FromContextError(err).Err()
	}
	if req.GetSku() == "" {
		return nil, status.Error(codes.InvalidArgument, "sku required")
	}
	s.mu.Lock()
	q, ok := s.stock[req.GetSku()]
	s.mu.Unlock()
	if !ok {
		return nil, status.Error(codes.NotFound, "sku not found")
	}
	return &pb.GetStockResponse{Sku: req.GetSku(), Quantity: q}, nil
}

func main() {
	lis, err := net.Listen("tcp", ":50051")
	if err != nil {
		log.Fatal(err)
	}
	s := grpc.NewServer(
		grpc.ChainUnaryInterceptor(unaryLog),
		grpc.MaxRecvMsgSize(1<<20),
	)
	pb.RegisterInventoryServer(s, &server{stock: map[string]int32{"A": 3}})
	log.Fatal(s.Serve(lis))
}
```

**Answer:** Client sees `Unimplemented`.

**Answer:** Compiler/API break or Unimplemented behavior — modern generators expect the embed.

## Rules and syntax

1. Embed `Unimplemented*Server`.  
2. First argument `ctx`.  
3. `status.Error` at the edge, not bare `errors.New` if you expect a code.  
4. Do not panic in RPC — return Internal or a recover interceptor.  
5. `GracefulStop` on signal.  
6. Interceptors for log/auth.  
7. Health service in production.  
8. Mutex/sync around shared map state.  
9. Port from env, not only hardcode.  
10. Be aware of `MaxRecvMsgSize`.

## Examples

### Example 1 — InvalidArgument

Empty sku/name → `InvalidArgument`. The client fixes the request.

### Example 2 — GracefulStop

```go
go func() { log.Fatal(s.Serve(lis)) }()
stop := make(chan os.Signal, 1)
signal.Notify(stop, os.Interrupt, syscall.SIGTERM)
<-stop
s.GracefulStop()
```

#### What happens here

`Serve` blocks for the life of the listener, so the snippet runs it in a goroutine and leaves `main` free to wait. `signal.Notify` forwards `os.Interrupt` and `syscall.SIGTERM` into a channel of size 1, and `<-stop` unblocks when one of those signals arrives. `s.GracefulStop()` then stops the server from accepting new RPCs and returns after handlers already in progress finish. When `Serve` returns, `log.Fatal` prints that result and exits the process.

In-flight RPCs finish; new ones are not accepted.

### Example 3 — unary log interceptor

Log `FullMethod` + `status.Code(err)` + duration + request id from MD.

### Example 4 — ctx into DB

```go
row, err := s.db.QueryRowContext(ctx, "select qty from stock where sku=$1", sku)
```

#### What happens here

`QueryRowContext` is invoked with the RPC `ctx`, so this stock lookup shares the handler’s deadline and cancellation. The SQL selects `qty` from `stock` for one sku, and the `$1` placeholder binds `sku` as a parameter. `row` and `err` hold the outcome the handler will turn into a response or a status. When the client deadline fires, that same `ctx` is what ends the wait on a slow query.

Deadline kills a slow query.

### Example 5 — bufconn test

```go
func TestGetStock(t *testing.T) {
	lis := bufconn.Listen(1024 * 1024)
	s := grpc.NewServer()
	pb.RegisterInventoryServer(s, &server{stock: map[string]int32{"A": 3}})
	go s.Serve(lis)
	conn, err := grpc.NewClient("passthrough:///bufnet",
		grpc.WithContextDialer(func(ctx context.Context, _ string) (net.Conn, error) {
			return lis.Dial()
		}),
		grpc.WithTransportCredentials(insecure.NewCredentials()),
	)
	// ... stub GetStock, assert
}
```

#### What happens here

`bufconn.Listen` creates an in-memory listener with a 1 MiB buffer, so the test never binds a TCP port. The snippet builds a `grpc.Server`, registers an `Inventory` implementation whose map already contains sku `A`, and serves that listener in a goroutine. `grpc.NewClient` uses the `passthrough` target `bufnet` and a dialer that returns `lis.Dial()`, which connects the stub to that same listener inside the process. `insecure.NewCredentials()` is the transport for this in-memory lab. The comment is where the test calls `GetStock` and asserts the quantity.

CI without a random port.

## Decision analysis

| API | When |
|-----|------|
| NewServer | default |
| ChainUnaryInterceptor | log+auth |
| Creds TLS | production |
| bufconn | unit/integration without TCP |
| reflection | lab / restricted prod |

## Trade-offs

A simple server stands up quickly; TLS, auth, and health add ceremony but are necessary outside the lab. An in-memory map is great for learning, bad for multi-instance without a store.

## Common mistakes

1. No Unimplemented embed.  
2. `errors.New` across the boundary.  
3. Ignored `ctx`.  
4. Listen hardcode without env.  
5. Reflection in prod without control.  
6. Blocking CPU work in RPC without offload.  
7. Shared map without sync.  
8. `Stop()` instead of `GracefulStop` under load.  
9. Mixing HTTP handler habits (no `ResponseWriter`).  
10. Forgotten Register after a refactor.

## Practical scenario

Second PR returns `errors.New` — the mobile gateway does not map. Third: status + embed + MaxRecvMsgSize + GracefulStop + bufconn smoke.

## Mechanism (deep dive): complete shutdown

```go
srv := grpc.NewServer()
// register...
go func() {
	if err := srv.Serve(lis); err != nil {
		log.Printf("serve: %v", err)
	}
}()

ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
defer stop()
<-ctx.Done()

stopped := make(chan struct{})
go func() {
	srv.GracefulStop()
	close(stopped)
}()
select {
case <-stopped:
case <-time.After(10 * time.Second):
	srv.Stop()
}
```

**Predict:** GracefulStop hangs forever because a client holds a stream.  
**Answer:** The timeout above then `Stop()`. A policy must exist.

## Mechanism (deep dive): auth interceptor sketch

```go
func unaryAuth(ctx context.Context, req any, info *grpc.UnaryServerInfo, handler grpc.UnaryHandler) (any, error) {
	if info.FullMethod == healthMethod {
		return handler(ctx, req)
	}
	md, ok := metadata.FromIncomingContext(ctx)
	if !ok {
		return nil, status.Error(codes.Unauthenticated, "missing metadata")
	}
	// validate authorization
	return handler(ctx, req)
}
```

**Predict:** Auth on the health method.  
**Answer:** Probes fail. Skip health.

## Mechanism (deep dive): Catalog stream note

For `List` the signature is `List(req, stream Catalog_ListServer) error` — you send with `stream.Send`. For `Upload`: `Recv` loop then `SendAndClose`. Status still through `return status.Error(...)`. Registration is the same `RegisterCatalogServer`.

## Predict-then-check

**A.** Two goroutines GetStock without mutex on the map.  
**Answer:** Data race. `go test -race`.

**B.** You return nil, nil.  
**Answer:** Often a bug — nil response with OK confuses clients. Return an empty message or an error deliberately.

**C.** Panic in the handler without a recover interceptor.  
**Answer:** May crash the process depending on version/settings — recover + metric.

**D.** MaxRecvMsgSize default + huge Upload chunk.  
**Answer:** ResourceExhausted / error. Limit and document.

**E.** TLS option forgotten in prod.  
**Answer:** Plaintext on the network. Lab only insecure.

## Mechanism (deep dive): auth interceptor sketch — continued

```go
func auth(ctx context.Context, req any, info *grpc.UnaryServerInfo, handler grpc.UnaryHandler) (any, error) {
	md, ok := metadata.FromIncomingContext(ctx)
	if !ok || len(md.Get("authorization")) == 0 {
		return nil, status.Error(codes.Unauthenticated, "missing auth")
	}
	// verify token → new ctx with principal
	return handler(ctx, req)
}
```

Do not log the token. Skip auth for health if needed.

## Mechanism (deep dive): server lab with race and ResourceExhausted

```go
func (s *catalogServer) Upload(stream demopb.Catalog_UploadServer) error {
	var n int64
	for {
		c, err := stream.Recv()
		if errors.Is(err, io.EOF) {
			return stream.SendAndClose(&demopb.UploadSummary{Bytes: n})
		}
		if err != nil {
			return err
		}
		n += int64(len(c.GetData()))
		if n > 8<<20 {
			return status.Error(codes.ResourceExhausted, "limit")
		}
	}
}
```

Race: 50 clients + GracefulStop — no panic, codes reasonable.

```text

```

