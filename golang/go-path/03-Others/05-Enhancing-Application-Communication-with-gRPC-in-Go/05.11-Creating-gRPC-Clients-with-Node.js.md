## Problem this lesson solves

Node clients forget the deadline, swallow the error without `code`, and mix legacy APIs. Module 05 must wrap up with proof: a Node client against a server in another language.

## Mental model

```text
load package definition
  → new Service('host:port', credentials)
       → GetStock(req, metadata?, options?, callback)
            → (err, resp)
```

Go counterpart: `NewClient` + stub + `WithTimeout`.

## Mechanism

```javascript
const grpc = require('@grpc/grpc-js');
const loader = require('@grpc/proto-loader');

const def = loader.loadSync('inventory.proto', {
  keepCase: true,
  longs: String,
  enums: String,
  defaults: true,
  oneofs: true,
});
const pkg = grpc.loadPackageDefinition(def).inventory.v1;

const client = new pkg.Inventory(
  '127.0.0.1:50051',
  grpc.credentials.createInsecure(), // lab only
);

const md = new grpc.Metadata();
md.set('x-request-id', 'lab-1');

client.GetStock(
  { sku: 'A' },
  md,
  { deadline: Date.now() + 200 },
  (err, resp) => {
    if (err) {
      console.log('code', err.code, 'msg', err.message);
      return;
    }
    console.log('qty', resp.quantity);
  },
);
```

## Rules and syntax

1. `@grpc/grpc-js`.  
2. `createInsecure` lab only.  
3. Deadline in call options.  
4. Read `err.code`.  
5. Metadata for rid/auth.  
6. Reuse the client object.  
7. Same proto / same loader options as the server team.  
8. Promise wrapper OK if it maps code.  
9. Do not log the token.  
10. Cross-language smoke before “done”.

## Examples

### Example 1 — code branch

```javascript
if (err && err.code === grpc.status.NOT_FOUND) {
  // UI
}
```

#### What happens here

The client callback receives `err` when the RPC finishes with a failure. The condition compares `err.code` with `grpc.status.NOT_FOUND`, the missing-sku code. The comment marks the UI branch for that case. A successful call leaves `err` null, so the `err &&` check skips the branch.

### Example 4 — Promise promisify

```javascript
const { promisify } = require('util');
const getStock = promisify(client.GetStock).bind(client);
try {
  const resp = await getStock({ sku: 'A' }, md, { deadline: Date.now() + 200 });
} catch (err) {
  console.log(err.code);
}
```

#### What happens here

`promisify` wraps the callback-style `client.GetStock` so the method returns a promise, and `.bind(client)` keeps the stub as `this`. The await sends `{ sku: 'A' }`, metadata `md`, and a deadline of `Date.now() + 200`, a timestamp 200 milliseconds ahead. A failed status rejects the promise. In the `catch`, `err.code` is still the gRPC status code.

### Example 5 — stream List sketch

```javascript
const call = client.List({ prefix: 'a' });
call.on('data', (item) => { /* ... */ });
call.on('error', (err) => { console.log(err.code); });
call.on('end', () => {});
```

#### What happens here

`client.List({ prefix: 'a' })` opens a server-streaming RPC with a single request. Each `data` event delivers one item the server wrote to the stream. The `error` listener receives a failure and can read `err.code`. The `end` listener runs when the server closes the stream after the last item.

## Decision analysis

| Choice | When |
|-------|------|
| callback | closest to the native API |
| promisify | async/await style |
| static codegen client | TS / larger projects |

## Trade-offs

Loader speed vs types. Callback clearly carries err; Promise requires code discipline.

## Mechanism (deep dive): deadline on the Node client

```js
const deadline = new Date(Date.now() + 800);
client.SayHello({ name: "Ana" }, { deadline }, (err, resp) => { /* ... */ });
```

Without a deadline, the call can hang. Same mental model as Go `WithTimeout` and Java `withDeadlineAfter`.

**Predict:** deadline in the past.  
**Answer:** immediate DEADLINE_EXCEEDED.

## Mechanism (deep dive): promisify caution

You can wrap unary in a Promise for `async/await`, but:

- streams are not the same model
- errors still carry `.code`
- do not lose the deadline in the wrapper

```js
function sayHelloAsync(client, name, ms) {
  return new Promise((resolve, reject) => {
    const deadline = new Date(Date.now() + ms);
    client.SayHello({ name }, { deadline }, (err, resp) => {
      if (err) reject(err);
      else resolve(resp);
    });
  });
}
```
