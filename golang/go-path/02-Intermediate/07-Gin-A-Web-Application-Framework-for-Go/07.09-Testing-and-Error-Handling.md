# 07.09 Testing and error handling in Gin

> **Go Path - Zero to Gopher** / **02 Intermediate → Gin: A Web Application Framework for Go** / Lesson 07.09

## Lesson goals

After this lesson you should be able to:

- extract **`setupRouter` / `NewRouter(deps)`** so main and test share the same Engine
- use `gin.TestMode`, `httptest.NewRecorder` + `Engine.ServeHTTP`
- write **table tests** for status codes and JSON keys
- treat **binding** errors as **400** (not 500)
- in POST tests set `Content-Type: application/json`
- verify the auth matrix **401** and **200**
- centralize `handleErr` with `errors.Is`; log internal errors, generic 500 to the client
- optionally know `c.Errors`; use `httptest.NewServer` for smoke
- connect the Gin module to the **08 Concurrency** bridge

## Prerequisite

- 07.04–07.08 (binding, responses, middleware, Logger/Recovery/auth demo)
- 06.09 (`httptest`, table tests in net/http)
- `encoding/json` in tests; `errors.Is`

## Problem this lesson solves

A Gin app without tests easily regresses:

- auth Abort forgotten — secret public again
- bind error returns 500 instead of 400
- error JSON shape is not the same on two routes
- main and test build different routes “temporarily” so the test lies green

Centralized error handling + an httptest suite keep the contract stable before you enter concurrency (module 08), where race and timeout make debug harder.

## Mental model

```text
NewRouter(deps) *gin.Engine   ← one source of truth
        │
        ├─ main: Run / RunTLS
        └─ test: ServeHTTP(rec, req)

Request in a test:
  httptest.NewRequest → (Body, Header) → r.ServeHTTP(rec, req)
  → assert Code + JSON keys

Error:
  binding → 400
  domain errors.Is → 404/409/...
  other → log + generic 500
```

1. **Router factory** — test and main share the same code.
2. Test builds a request → `r.ServeHTTP(rec, req)` → assert.
3. Handler uses `handleErr`; does not leak `err.Error()` from DB.
4. Never mask binding errors as 500.
5. `gin.Context` in the handler; the service gets `c.Request.Context()`.

## Mechanism

### setupRouter / NewRouter(deps)

```go
type Deps struct {
	Token string
	Svc   ItemService
}

func NewRouter(d Deps) *gin.Engine {
	r := gin.New()
	r.Use(gin.Recovery())
	r.GET("/health", func(c *gin.Context) { c.Status(http.StatusOK) })
	api := r.Group("/api")
	api.Use(tokenAuth(d.Token))
	api.GET("/items/:id", getItem(d.Svc))
	api.POST("/items", createItem(d.Svc))
	return r
}
```

In the test: `gin.SetMode(gin.TestMode)` once (e.g. in `TestMain` or at the start of the package). TestMode reduces Logger noise if you turn it on.

### httptest recorder + ServeHTTP

```go
func TestHealth(t *testing.T) {
	gin.SetMode(gin.TestMode)
	r := NewRouter(Deps{Token: "t"})
	req := httptest.NewRequest(http.MethodGet, "/health", nil)
	rec := httptest.NewRecorder()
	r.ServeHTTP(rec, req)
	if rec.Code != http.StatusOK {
		t.Fatalf("code=%d", rec.Code)
	}
}
```

No real TCP port. Engine treats the recorder as ResponseWriter. Fast, deterministic.

### Table tests: status + JSON keys

```go
func TestSecretAuth(t *testing.T) {
	gin.SetMode(gin.TestMode)
	r := NewRouter(Deps{Token: "secret"})
	tests := []struct {
		name   string
		token  string
		code   int
		hasKey string
	}{
		{"no token", "", http.StatusUnauthorized, "error"},
		{"good token", "secret", http.StatusOK, "secret"},
	}
	for _, tt := range tests {
		t.Run(tt.name, func(t *testing.T) {
			req := httptest.NewRequest(http.MethodGet, "/api/secret", nil)
			if tt.token != "" {
				req.Header.Set("X-Token", tt.token)
			}
			rec := httptest.NewRecorder()
			r.ServeHTTP(rec, req)
			if rec.Code != tt.code {
				t.Fatalf("code=%d want=%d body=%s", rec.Code, tt.code, rec.Body.String())
			}
			var body map[string]any
			if err := json.Unmarshal(rec.Body.Bytes(), &body); err != nil && tt.hasKey != "" {
				t.Fatalf("json: %v", err)
			}
			if tt.hasKey != "" {
				if _, ok := body[tt.hasKey]; !ok {
					t.Fatalf("missing key %q in %v", tt.hasKey, body)
				}
			}
		})
	}
}
```

Assert the envelope **key** (`error`, `id`), not full indented string equality — more stable.

### Binding fail → 400

```go
func createItem(svc ItemService) gin.HandlerFunc {
	return func(c *gin.Context) {
		var in struct {
			Name string `json:"name" binding:"required"`
		}
		if err := c.ShouldBindJSON(&in); err != nil {
			c.AbortWithStatusJSON(http.StatusBadRequest, gin.H{"error": "invalid input"})
			return
		}
		id, err := svc.Create(c.Request.Context(), in.Name)
		if err != nil {
			handleErr(c, err)
			return
		}
		c.JSON(http.StatusCreated, gin.H{"id": id})
	}
}
```

In the test you **must** set Content-Type:

```go
req := httptest.NewRequest(http.MethodPost, "/api/items", bytes.NewBufferString(`{}`))
req.Header.Set("Content-Type", "application/json")
req.Header.Set("X-Token", "secret")
```

Without Content-Type binding may behave differently / fail — the test must look like a real client.

**Predict:** `{}` with `binding:"required"` on Name — which status?

**Answer:** 400, not 500. The service is not called.

### handleErr + errors.Is

```go
var (
	errNotFound = errors.New("not found")
	errConflict = errors.New("conflict")
)

func handleErr(c *gin.Context, err error) {
	switch {
	case errors.Is(err, errNotFound):
		c.AbortWithStatusJSON(http.StatusNotFound, gin.H{"error": "not found"})
	case errors.Is(err, errConflict):
		c.AbortWithStatusJSON(http.StatusConflict, gin.H{"error": "conflict"})
	default:
		log.Printf("internal: %v req=%s", err, c.GetString("reqID"))
		c.AbortWithStatusJSON(http.StatusInternalServerError, gin.H{"error": "internal error"})
	}
}
```

The internal `error` does **not** go into JSON. A 500 test checks the generic key `error` and if needed that the body does **not** contain `"sql:"` / `"pq:"`.

### Optional: c.Errors

```go
c.Error(err) // collects errors on Context
```

Some styles have middleware that at the end reads `c.Errors` and maps the response. For this path prefer explicit `handleErr` — clearer for beginners and table tests. We mention `c.Errors` so you recognize it in other people’s code.

### httptest.NewServer smoke

```go
func TestSmokeServer(t *testing.T) {
	gin.SetMode(gin.TestMode)
	r := NewRouter(Deps{Token: "t"})
	srv := httptest.NewServer(r)
	defer srv.Close()

	res, err := http.Get(srv.URL + "/health")
	if err != nil {
		t.Fatal(err)
	}
	defer res.Body.Close()
	if res.StatusCode != http.StatusOK {
		t.Fatalf("status=%d", res.StatusCode)
	}
}
```

Use when you want a real client + URL. Still the same `NewRouter`. Slower than pure ServeHTTP — leave for a small number of smoke tests.

### Same router as main

```go
func main() {
	r := NewRouter(Deps{Token: os.Getenv("API_TOKEN"), Svc: ItemService{}})
	_ = r.Run(":8080")
}
```

If the test “manually” registers different routes, it tests a fake application. Rule: **only the factory**.

### Execution trace: table auth

```text
for each tt:
  NewRequest GET /api/secret
  optionally Header X-Token
  ServeHTTP
  check Code
  Unmarshal JSON
  check key
```

### Predict: 500 leak

The handler does `c.JSON(500, gin.H{"error": err.Error()})` with `err = errors.New("pq: duplicate")`. The test should?

**Answer:** fail if you assert the body does not contain `pq:`; or better — refactor to handleErr and assert `"internal error"` / generic text.

### Bridge to module 08

So far: one request, one chain, test without a race. Module 08 introduces **concurrency** (concurrency — gloss): goroutine, channel, race. Gin handlers can start background work — remember `c.Copy()` from 07.07. Concurrency tests need `-race` and different fixtures. This lesson locks the HTTP contract **before** that complexity.

## Rules and syntax

1. One `NewRouter(deps)` for main and test.
2. `gin.TestMode` in the test package.
3. `httptest` + `ServeHTTP` as default; `NewServer` for smoke.
4. Table tests: code + JSON keys.
5. POST: `Content-Type: application/json` + token header when needed.
6. Binding error → 400 + Abort + return.
7. `handleErr` + `errors.Is`; default log + generic 500.
8. Do not leak `err.Error()` from infra into JSON.
9. Auth matrix: 401 and 200 mandatory cases.
10. Do not build a parallel “test-only” router with different rules.
11. Service in the test: fake/stub with controlled error.
12. Bridge: stable API contract before the concurrency module.

## Examples

### Example 1: Table test ping and 404

```go
func TestGetItem(t *testing.T) {
	gin.SetMode(gin.TestMode)
	svc := stubSvc{items: map[string]string{"1": "mug"}}
	r := NewRouter(Deps{Token: "t", Svc: svc})

	tests := []struct {
		name string
		id   string
		code int
		key  string
	}{
		{"exists", "1", http.StatusOK, "name"},
		{"missing", "9", http.StatusNotFound, "error"},
	}
	for _, tt := range tests {
		t.Run(tt.name, func(t *testing.T) {
			req := httptest.NewRequest(http.MethodGet, "/api/items/"+tt.id, nil)
			req.Header.Set("X-Token", "t")
			rec := httptest.NewRecorder()
			r.ServeHTTP(rec, req)
			if rec.Code != tt.code {
				t.Fatalf("got %d want %d body=%s", rec.Code, tt.code, rec.Body.String())
			}
			var m map[string]any
			_ = json.Unmarshal(rec.Body.Bytes(), &m)
			if _, ok := m[tt.key]; !ok {
				t.Fatalf("missing %s: %v", tt.key, m)
			}
		})
	}
}

type stubSvc struct {
	items map[string]string
}

func (s stubSvc) Get(ctx context.Context, id string) (map[string]string, error) {
	_ = ctx
	v, ok := s.items[id]
	if !ok {
		return nil, errNotFound
	}
	return map[string]string{"id": id, "name": v}, nil
}

func (s stubSvc) Create(ctx context.Context, name string) (string, error) {
	_ = ctx
	if name == "dup" {
		return "", errConflict
	}
	return "7", nil
}
```

#### What happens here

Same router as production. Stub controls not found. Table covers 200 and 404. Token header required because the route is in the auth group.

### Example 2: Binding 400 with Content-Type

```go
func TestCreateBind(t *testing.T) {
	gin.SetMode(gin.TestMode)
	r := NewRouter(Deps{Token: "t", Svc: stubSvc{}})
	req := httptest.NewRequest(http.MethodPost, "/api/items", bytes.NewBufferString(`{}`))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("X-Token", "t")
	rec := httptest.NewRecorder()
	r.ServeHTTP(rec, req)
	if rec.Code != http.StatusBadRequest {
		t.Fatalf("code=%d body=%s", rec.Code, rec.Body.String())
	}
}
```

#### What happens here

Empty object does not satisfy required name → 400. Without Content-Type the test would be fake. **Predict:** wrong token + `{}` — what first? **Answer:** 401 from auth middleware before binding.

### Example 3: Conflict 409 via handleErr

```go
func TestCreateConflict(t *testing.T) {
	gin.SetMode(gin.TestMode)
	r := NewRouter(Deps{Token: "t", Svc: stubSvc{}})
	body := `{"name":"dup"}`
	req := httptest.NewRequest(http.MethodPost, "/api/items", bytes.NewBufferString(body))
	req.Header.Set("Content-Type", "application/json")
	req.Header.Set("X-Token", "t")
	rec := httptest.NewRecorder()
	r.ServeHTTP(rec, req)
	if rec.Code != http.StatusConflict {
		t.Fatalf("code=%d", rec.Code)
	}
	if !bytes.Contains(rec.Body.Bytes(), []byte(`"error"`)) {
		t.Fatalf("envelope: %s", rec.Body.String())
	}
}
```

#### What happens here

Binding passes; service returns errConflict; handleErr → 409. No SQL text in the body.

### Example 4: Internal err does not leak

```go
type boomSvc struct{}

func (boomSvc) Get(ctx context.Context, id string) (map[string]string, error) {
	return nil, errors.New("pq: connection refused")
}
func (boomSvc) Create(ctx context.Context, name string) (string, error) {
	return "", errors.New("pq: connection refused")
}

func TestNoLeak(t *testing.T) {
	gin.SetMode(gin.TestMode)
	r := NewRouter(Deps{Token: "t", Svc: boomSvc{}})
	req := httptest.NewRequest(http.MethodGet, "/api/items/1", nil)
	req.Header.Set("X-Token", "t")
	rec := httptest.NewRecorder()
	r.ServeHTTP(rec, req)
	if rec.Code != http.StatusInternalServerError {
		t.Fatalf("code=%d", rec.Code)
	}
	if bytes.Contains(rec.Body.Bytes(), []byte("pq:")) {
		t.Fatalf("leak: %s", rec.Body.String())
	}
}
```

#### What happens here

Default branch of handleErr. The test protects the contract “client does not see the driver”. The log (not asserted here) still has the detail.

### Example 5: NewServer smoke

```go
func TestHealthSmoke(t *testing.T) {
	gin.SetMode(gin.TestMode)
	srv := httptest.NewServer(NewRouter(Deps{Token: "t"}))
	t.Cleanup(srv.Close)
	res, err := http.Get(srv.URL + "/health")
	if err != nil {
		t.Fatal(err)
	}
	defer res.Body.Close()
	if res.StatusCode != 200 {
		t.Fatalf("status=%d", res.StatusCode)
	}
}
```

#### What happens here

Real HTTP client, same router. Smoke confirms Engine works as http.Handler.

### Example 6: TestMain and TestMode

```go
func TestMain(m *testing.M) {
	gin.SetMode(gin.TestMode)
	os.Exit(m.Run())
}
```

#### What happens here

Once for the package. All tests inherit TestMode without repetition — or explicitly at the top of each test if you prefer locality.

## Decision analysis

| Decision | Choice | Why |
|----------|--------|-----|
| Router | NewRouter(deps) | same code main/test |
| Test transport | ServeHTTP | speed |
| Assert body | JSON keys | less brittleness |
| Bind error | 400 | semantically correct |
| DB error | log + generic 500 | no leak |
| Fake svc | stub interface | controlled errors.Is |
| c.Errors mw | optional later | handleErr clearer now |

## Trade-offs

- **ServeHTTP vs NewServer** — speed vs more realistic client.
- **map[string]any assert** — fast; weaker than typed DTO decode.
- **One stub for all** — simple; when it grows, mock per interface.
- **TestMain global mode** — less noise; hides explicitness.
- **Snapshot of the whole JSON string** — strict; breaks on field reordering.

## Common mistakes

1. **Wrong:** a different router only for the test.  
   **Effect:** falsely green tests.  
   **Fix:** same NewRouter.

2. **Wrong:** POST without Content-Type.  
   **Effect:** fake fail/pass of binding.  
   **Fix:** `application/json`.

3. **Wrong:** bind fail → 500.  
   **Effect:** client retries wrongly; alarms.  
   **Fix:** 400.

4. **Wrong:** assert `rec.Body.String() == exact`.  
   **Effect:** brittle tests.  
   **Fix:** code + keys / Decode into struct.

5. **Wrong:** `err.Error()` in JSON 500.  
   **Effect:** leak.  
   **Fix:** handleErr default + anti-leak test.

6. **Wrong:** no 401 case in the auth test.  
   **Effect:** Abort regress passes.  
   **Fix:** table with empty token.

7. **Wrong:** real DB in a unit handler test.  
   **Effect:** slow/flaky.  
   **Fix:** service stub; leave DB for integration.

8. **Wrong:** forgotten token on a protected route in a “success” test.  
   **Effect:** tests 401 instead of business.  
   **Fix:** header on the happy path.

## Idiomatic Go

- `NewRouter(Deps)` in `internal/httpapi`.
- Narrow service interface (Get/Create).
- Table driven tests (`t.Run`).
- `errors.Is` + sentinel in the service package.
- Anti-leak test for 500.
- Same envelope assert helper (`decodeError(t, rec)`).

## Practical scenario

Before release QA finds that an empty POST returns 500 because someone replaced the ShouldBind branch with `log.Fatal` / panic. They add a table test `{}` → 400; CI goes red on a PR that introduces 500 again. Another PR “simplifies” error JSON to `err.Error()` — the anti-leak test with `pq:` fails. A third removes auth “temporarily” from the test router to write tests more easily — production stays protected, tests lie; code review enforces NewRouter. After the team stabilizes, they move to module 08 with a calmer HTTP foundation.

## Check questions

1. Why share NewRouter?  
   **Answer:** so you test the same chain as production.

2. How do you send a request without a port?  
   **Answer:** `httptest.NewRequest` + `r.ServeHTTP(rec, req)`.

3. Binding error — which status?  
   **Answer:** 400.

4. Why Content-Type in a POST test?  
   **Answer:** so the binder treats the body as JSON like a real client.

5. How do you map a domain error?  
   **Answer:** `errors.Is` in `handleErr`.

6. What does the client see on an unexpected DB error?  
   **Answer:** a generic 500 envelope; detail in the log.

7. What is TestMode for?  
   **Answer:** reduces Gin noise / sets the mode for tests.

8. When NewServer?  
   **Answer:** smoke with a real HTTP client; most tests stay on ServeHTTP.

POST /api/items without token, body `{"name":"x"}`.

**Answer:** 401; create handler (bind) does not run.

### Predict: table miss

The test only asserts `code==200` for secret with token, never without token. Someone deletes `api.Use(auth)`.

**Answer:** the test still passes — that is why you need a 401 case in the matrix.

### Predict: context

```go
id, err := svc.Create(context.Background(), in.Name)
```

instead of Request Context in the handler. What do you lose?

**Answer:** client cancellation / timeout is not passed into the service/DB — worse behavior under pressure; even more important in 08.

### Helpers for readable tests

```go
func perform(r http.Handler, method, path string, body string, hdr map[string]string) *httptest.ResponseRecorder {
	var rd io.Reader
	if body != "" {
		rd = bytes.NewBufferString(body)
	}
	req := httptest.NewRequest(method, path, rd)
	for k, v := range hdr {
		req.Header.Set(k, v)
	}
	rec := httptest.NewRecorder()
	r.ServeHTTP(rec, req)
	return rec
}

func assertCode(t *testing.T, rec *httptest.ResponseRecorder, want int) {
	t.Helper()
	if rec.Code != want {
		t.Fatalf("code=%d want=%d body=%s", rec.Code, want, rec.Body.String())
	}
}

func assertJSONKey(t *testing.T, rec *httptest.ResponseRecorder, key string) {
	t.Helper()
	var m map[string]any
	if err := json.Unmarshal(rec.Body.Bytes(), &m); err != nil {
		t.Fatalf("json: %v body=%s", err, rec.Body.String())
	}
	if _, ok := m[key]; !ok {
		t.Fatalf("missing key %q in %v", key, m)
	}
}
```

`t.Helper()` makes the fail line show the caller, not the helper. Reduces noise in table tests.

### Matrix CI should keep

| Test | Method | Path | Headers | Body | Want |
|------|--------|------|---------|------|------|
| health | GET | /health | — | — | 200 |
| secret anon | GET | /api/secret | — | — | 401 + error |
| secret ok | GET | /api/secret | X-Token | — | 200 + secret |
| create bad | POST | /api/items | token+CT | `{}` | 400 + error |
| create ok | POST | /api/items | token+CT | `{"name":"a"}` | 201 + id |
| create dup | POST | /api/items | token+CT | `{"name":"dup"}` | 409 + error |
| get missing | GET | /api/items/9 | token | — | 404 + error |
| get leak | GET | /api/items/1 | token | — | 500 without pq |

If a PR touches auth/binding/handleErr, this matrix catches the regression.

### Fake service and interface

```go
type ItemService interface {
	Get(ctx context.Context, id string) (map[string]string, error)
	Create(ctx context.Context, name string) (string, error)

```

Production: `dbItemService`. Test: `stubSvc` / `boomSvc`. Handler depends on the interface — idiomatic Go. Do not export `*gin.Context` into the service.

### What not to test in this layer

- Performance under a thousand RPS (another place).
- Real JWT signature of a library (unit that library / small adapter test).
- UI browser clicks (e2e separately).

### Bridge to 08 — what changes in tests

In 08 you learn goroutine and channel. When a handler starts `go` work:

- use `c.Copy()` (07.07)
- the test may need `sync` / timeout to wait for a side-effect
- run `go test -race`

Without solid tests from this lesson, race debug mixes “wrong status” with “data race”. So lock the contract first.

### Example: create success 201

```go
func TestCreateOK(t *testing.T) {
	gin.SetMode(gin.TestMode)
	r := NewRouter(Deps{Token: "t", Svc: stubSvc{}})
	rec := perform(r, http.MethodPost, "/api/items", `{"name":"mug"}`, map[string]string{
		"Content-Type": "application/json",
		"X-Token":      "t",
	})
	assertCode(t, rec, http.StatusCreated)
	assertJSONKey(t, rec, "id")
}
```

#### What happens here

Happy path after bind + stub Create. Status 201. Key `id` exists. You can additionally assert the Location header with `rec.Header().Get("Location")` if the handler sets it (07.05).

### Checking the Location header

```go
if loc := rec.Header().Get("Location"); loc == "" {
	t.Fatal("expected Location")
}
```

Headers are part of the contract the same as JSON — 07.06 insists on order; the test locks that.

### Negative test: body is not JSON

```go
rec := perform(r, http.MethodPost, "/api/items", `not-json`, map[string]string{
	"Content-Type": "application/json",
	"X-Token":      "t",
})
assertCode(t, rec, http.StatusBadRequest)
```

ShouldBindJSON fails → 400. Not 500.

### File organization


## Summary

- `NewRouter(deps)` + TestMode + httptest ServeHTTP are the foundation.
- Table tests: status and JSON keys; POST with Content-Type; auth 401 and 200.
- Binding → 400; handleErr + errors.Is; internal err in the log, not to the client.
- Optional c.Errors; NewServer smoke; same router as main.
- A stable Gin contract is the bridge to 08 — concurrency in Go.
