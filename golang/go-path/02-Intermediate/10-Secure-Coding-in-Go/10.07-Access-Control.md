# 10.07 Access Control

> **Go Path - Zero to Gopher** / **02 Intermediate → Secure Coding in Go** / Lesson 10.07

## Lesson goals

After this lesson you should:

- separate **authentication** (who you are) from **authorization** (whether you may perform an action)
- check authorization **on the server for every request**; deny by default
- tie the decision to the resource (`owner_id`) not only to “is logged in”
- use `context` principal from session (10.06)
- audit deny/allow for sensitive actions without logging secrets

## Prerequisite

- 10.05–10.06; HTTP middleware
- 10.01 least privilege

## Problem this lesson solves

Login is not permission for everything. Classic failure: endpoint checks session but not whether the order is *yours* or whether the role allows refund. That breaks confidentiality of others’ data and integrity of monetary actions.

## Mental model

1. **Authn** — Principal{UserID, Roles}.
2. **Authz** — `Can(action, resource)` → bool; default false.
3. **Every request** — do not cache allow forever without TTL/invalidation.
4. **Object check** — `resource.OwnerID == principal.UserID` or role.
5. **Fail closed** — store error ≠ allow.

```text
RequireSession → Principal in ctx → RequireCan / CanOwn → handler → SQL with owner filter
```

## Mechanism

### Deny by default

```go
func (p Principal) Can(action string) bool {
	_, ok := p.Roles[action]
	return ok
}
```

Empty Roles → false. Never `if !isBanned` as the only check.

### Role vs ownership

| Type | Example |
|-----|--------|
| RBAC | `finance.refund` |
| Ownership | read invoice if `owner_id` |
| Both | support reads with audit; owner reads own |

### IDOR defense trace

```text
id from path → validate
principal from ctx
load resource by id
if resource.Owner != principal.UserID && !principal.Can("support.read") → 403
else return
```

Without ownership check, knowing ID opens another user’s record — impact on confidentiality. Defense is server check, not hiding a button.

### Policy table

Keep permissions explicit (code or config), not scattered through handlers without action name.

### Audit

```go
slog.Warn("authz_deny", "actor", id, "action", action, "resource", rid)
```

No tokens and excess PII.

### Cache Can()

Short TTL; invalidation on role change/logout. Otherwise authz integrity suffers.

### SQL link

Authz in application + `WHERE id=$1 AND owner_id=$2` — defense in depth (10.12).

## Rules

1. Authz on server every time.
2. Deny by default.
3. Name actions (`order.refund`), not only “admin bool”.
4. Ownership for user resources.
5. Fail closed on policy evaluation error.
6. Do not trust client role headers.
7. Audit sensitive allow/deny.

## Examples

### Example 1 — Can and RequireCan

```go
type Principal struct {
	UserID string
	Roles  map[string]struct{}
}

func (p Principal) Can(action string) bool {
	if p.Roles == nil {
		return false
	}
	_, ok := p.Roles[action]
	return ok
}

func RequireCan(action string, next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		p, ok := PrincipalFrom(r.Context())
		if !ok || !p.Can(action) {
			http.Error(w, "forbidden", http.StatusForbidden)
			return
		}
		next.ServeHTTP(w, r)
	})
}
```

#### What happens here

Explicit action; zero value deny; 403 without internals.

### Example 2 — ownership

```go
func (h *Handler) GetOrder(w http.ResponseWriter, r *http.Request) {
	p, ok := PrincipalFrom(r.Context())
	if !ok {
		http.Error(w, "unauthorized", http.StatusUnauthorized)
		return
	}
	id := r.PathValue("id")
	o, err := h.repo.ByID(r.Context(), id)
	if err != nil {
		http.Error(w, "not found", http.StatusNotFound)
		return
	}
	if o.OwnerID != p.UserID && !p.Can("support.orders.read") {
		http.Error(w, "forbidden", http.StatusForbidden)
		return
	}
	_ = json.NewEncoder(w).Encode(o)
}
```

#### What happens here

Session is not enough; ownership or support role. 404 vs 403 — team policy (sometimes unified 404 for privacy).

## Decision analysis

| Decision | Why |
|--------|-------|
| Separate authn/authz | clear 401 vs 403 errors |
| Named actions | review and audit |
| Ownership + RBAC | least privilege |
| SQL filter | defense in depth |
| Deny default | zero value safe |

## Trade-offs

- **Fine-grained actions** = more policy entries.
- **Unified 404** harder UX debug, improves privacy.
- **Support role** broad — requires audit and time-limited elevation.
- **Cache** speed vs fresh revoke.

## Common mistakes

1. Only “has session”.
2. Roles from client header.
3. Fail open.
4. No ownership.
5. One `IsAdmin` for everything.
6. Authz only on frontend routes.
7. Cache allow forever.
8. Mixing 401/403 without policy.
9. Logging whole principal secret material.
10. Believing VPN replaces Can().

## Idiomatic Go

- Middleware factory `RequireCan(action)`.
- Principal in context.
- Table tests deny/allow.
- Small package `authz`.

## Practical scenario

Refund endpoint checks only cookie. Threat model → `finance.refund` + audit + SQL without DDL. Leaked user session no longer refunds.

### API focus: RequireCan middleware

Authorization runs after authentication and validation. Middleware checks `Principal.Can(action)` before handler — deny by default.

```go
func RequireCan(action string, next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		p, ok := PrincipalFrom(r.Context())
		if !ok || !p.Can(action) {
			http.Error(w, "forbidden", http.StatusForbidden)
			return
		}
		next.ServeHTTP(w, r)
	})
}
```

### API focus: Principal.Can

```go
type Principal struct {
	UserID string
	Roles  map[string]struct{}
}

func (p Principal) Can(action string) bool {
	if p.UserID == "" {
		return false
	}
	allowed, ok := roleActions[p.primaryRole(p.Roles)]
	if !ok {
		return false
	}
	_, ok = allowed[action]
	return ok
}
```

### API focus: ownership check

Object-level authz — valid ID is not enough.

```go
func (s *Service) DeleteNote(ctx context.Context, p Principal, id uuid.UUID) error {
	n, err := s.repo.Get(ctx, id)
	if err != nil {
		return err
	}
	if n.OwnerID != p.UserID && !p.Can("notes.delete_any") {
		return ErrForbidden
	}
	return s.repo.Delete(ctx, id, n.OwnerID)
}
```

### API focus: ABAC Authorize fn

Fine-grained rules in one table-driven tested function.

```go
func Authorize(p Principal, res Resource, act Action) error {
	if res.OwnerID == p.UserID {
		return nil
	}
	if p.Can(string(act)) {
		return nil
	}
	return ErrForbidden
}
```

### API focus: policy table test

```go
func TestPolicyTable(t *testing.T) {
	cases := []struct {
		role string
		act  string
		want bool
	}{
		{"viewer", "notes.write", false},
		{"editor", "notes.write", true},
	}
	for _, tc := range cases {
		p := Principal{Roles: map[string]struct{}{tc.role: {}}}
		if got := p.Can(tc.act); got != tc.want {
			t.Fatalf("role=%s act=%s got=%v", tc.role, tc.act, got)
		}
	}
}
```
