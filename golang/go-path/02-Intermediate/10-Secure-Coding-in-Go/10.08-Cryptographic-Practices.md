# 10.08 Cryptographic Practices

> **Go Path - Zero to Gopher** / **02 Intermediate → Secure Coding in Go** / Lesson 10.08

## Lesson goals

After this lesson you should:

- use `crypto/rand` for all security-relevant bytes
- understand TLS as transport layer (details in 10.10)
- apply **AES-GCM** (AEAD) via `crypto/cipher` for data at rest — no custom modes
- separate keys by purpose; store them outside source
- know what you must not “assemble yourself” (ECB, XOR “cipher”, repeated GCM nonce)

## Prerequisite

- 10.01, 10.05; nonce/key concepts
- `crypto/aes`, `crypto/cipher`, `crypto/rand`

## Problem this lesson solves

Inventiveness in crypto breaks guarantees: wrong mode, repeated nonce, `math/rand` for key. Go stdlib offers proven primitives; your job is correct call and key storage.

## Mental model

1. **Randomness** — crypto/rand.
2. **Transport** — TLS (10.10), not homemade TCP encryption.
3. **AEAD** — confidentiality + integrity (AES-GCM).
4. **Nonce** — unique per Seal under same key.
5. **Key** — 16/24/32 bytes; secret store/env; per purpose.

## Mechanism

### crypto/rand

```go
key := make([]byte, 32)
if _, err := rand.Read(key); err != nil {
	return err
}
```

Fail closed on error.

### AES-GCM API

```go
block, err := aes.NewCipher(key)
gcm, err := cipher.NewGCM(block)
nonce := make([]byte, gcm.NonceSize())
rand.Read(nonce)
ct := gcm.Seal(nil, nonce, plaintext, aad)
pt, err := gcm.Open(nil, nonce, ct, aad)
```

`Open` error = wrong key, nonce, ciphertext or AAD — treat as integrity failure.

### Why AEAD

Encryption without authentication allows invisible ciphertext changes. GCM provides tag. Do not invent “AES-CBC + own HMAC” unless you follow a complete, reviewed protocol — for this course: GCM.

### What to avoid

- ECB (same block → same ciphertext pattern)
- Repeating GCM nonce with same key (disaster for GCM)
- math/rand for key/nonce
- Logging plaintext/key

### Seal trace

```text
load key from env
NewCipher → NewGCM
rand nonce
Seal(plain, aad)
store nonce|ciphertext (document format)
```


</details>

### AAD

Additional authenticated data (e.g. record version, tenant ID) is not encrypted but is authenticated — Open fails if AAD does not match.

### TLS vs at-rest

TLS protects in transit. AES-GCM protects in database/file. Both often needed (10.09, 10.10).

## Rules

1. Only crypto/rand for key/nonce/token.
2. AES-GCM for application encryption at rest in this course.
3. New nonce per Seal.
4. Check Open error.
5. Keys outside source; separated by purpose.
6. Do not log plaintext/key.
7. Do not use ECB / homemade.

## Examples

### Example 1 — EncryptAESGCM / DecryptAESGCM

```go
package cryptoutil

import (
	"crypto/aes"
	"crypto/cipher"
	"crypto/rand"
	"fmt"
	"io"
)

func EncryptAESGCM(key, plaintext, aad []byte) (nonce, ciphertext []byte, err error) {
	block, err := aes.NewCipher(key)
	if err != nil {
		return nil, nil, err
	}
	gcm, err := cipher.NewGCM(block)
	if err != nil {
		return nil, nil, err
	}
	nonce = make([]byte, gcm.NonceSize())
	if _, err = io.ReadFull(rand.Reader, nonce); err != nil {
		return nil, nil, err
	}
	ciphertext = gcm.Seal(nil, nonce, plaintext, aad)
	return nonce, ciphertext, nil
}

func DecryptAESGCM(key, nonce, ciphertext, aad []byte) ([]byte, error) {
	block, err := aes.NewCipher(key)
	if err != nil {
		return nil, err
	}
	gcm, err := cipher.NewGCM(block)
	if err != nil {
		return nil, err
	}
	pt, err := gcm.Open(nil, nonce, ciphertext, aad)
	if err != nil {
		return nil, fmt.Errorf("open: %w", err)
	}
	return pt, nil
}
```

#### What happens here

Proper stdlib AEAD. Nonce from rand.Reader. Open error not ignored.

## Decision analysis

| Decision | Why |
|--------|-------|
| AES-GCM | AEAD in stdlib |
| Separate keys | least privilege |
| Rand nonce | GCM requirement |
| Env/store key | confidentiality |

## Trade-offs

- **Key management** harder than “TLS only”.
- **Key rotation** requires version in record.
- **GCM nonce size** — use `gcm.NonceSize()`, do not guess.

2. Fixed nonce.
3. ECB.
4. Key in git.
5. Ignoring Open.
6. One key for everything.
7. Log plaintext.

### Key rotation (version in record)

```go
type Sealed struct {
	KeyVer int
	Nonce  []byte
	CT     []byte
}

func OpenVersioned(keys map[int][]byte, s Sealed, aad []byte) ([]byte, error) {
	key, ok := keys[s.KeyVer]
	if !ok {
		return nil, fmt.Errorf("unknown key version")
	}
	return DecryptAESGCM(key, s.Nonce, s.CT, aad)
}
```

#### What happens here

New key version does not delete old records immediately. Least privilege: old key remains for read during migration, then withdrawn.

### Table of forbidden constructions

| construction | why not |
|--------------|----------|
| ECB | patterns in ciphertext |
| math/rand nonce | predictability |
| fixed IV | GCM disaster / weak modes |
| MD5(password) | not KDF nor AEAD |
| XOR with key | no integrity |
| one master key for all | blast radius |

### Mini exercise in mind: AAD

If AAD includes `tenantID`, and an attacker swaps ciphertext from tenant A into tenant B row (same key), Open should fail because AAD does not match. That is context integrity — why AAD is not optional decoration.

### Test roundtrip and negative

```go
func TestGCMRoundTrip(t *testing.T) {
	key := make([]byte, 32)
	_, _ = rand.Read(key)
	n, ct, err := EncryptAESGCM(key, []byte("secret"), []byte("aad"))
	if err != nil {
		t.Fatal(err)
	}
	pt, err := DecryptAESGCM(key, n, ct, []byte("aad"))
	if err != nil || string(pt) != "secret" {
		t.Fatalf("%v %q", err, pt)
	}
	_, err = DecryptAESGCM(key, n, ct, []byte("other"))
	if err == nil {
		t.Fatal("expected AAD mismatch error")
	}
}
```

#### What happens here

Positive path and AAD integrity. No offensive content — defensive assert only.

### Link to password KDF (10.05)

Do not put passwords in AES-GCM as bcrypt replacement. GCM is for *data*. Passwords: KDF hash. Tokens: crypto/rand. Different tools for different secrets.

### Operational checklist before merge

```text
[ ] Key 32 bytes from env/store
[ ] Nonce from rand per Seal
[ ] Storage format documented
[ ] Open error → generic response
[ ] No key in log/test fixture git
```

### Scenario compromise disk dump only

Without key: ciphertext unrevealed (confidentiality goal). With key in same dump (wrong ops): AEAD does not help — so key and data must not live in same backup bucket with same ACL (least privilege ops).

### Another predict: Seal dst overlapping

Use `Seal(nil, ...)` or carefully documented dst. Do not optimize prematurely by overlapping buffers before reading `cipher.AEAD` docs — mistakes there break integrity.

### API focus: crypto/aes.NewCipher

AES-256 key must be exactly 16, 24 or 32 bytes from `crypto/rand`. Never password as key without KDF.

```go
key := make([]byte, 32)
if _, err := rand.Read(key); err != nil {
	return err
}
block, err := aes.NewCipher(key)
if err != nil {
	return err
}
_ = block
```

### API focus: cipher.NewGCM

GCM provides AEAD — encryption + integrity. Use unique nonce per message.

```go
gcm, err := cipher.NewGCM(block)
if err != nil {
	return err
}
nonce := make([]byte, gcm.NonceSize())
if _, err := rand.Read(nonce); err != nil {
	return err
}
```

### API focus: gcm.Seal

Pack ciphertext nonce || seal output — or store nonce separately, but always unique.

```go
func Encrypt(key, plaintext []byte) ([]byte, error) {
	block, err := aes.NewCipher(key)
	if err != nil {
		return nil, err
	}
	gcm, err := cipher.NewGCM(block)
	if err != nil {
		return nil, err
	}
	nonce := make([]byte, gcm.NonceSize())
	if _, err := rand.Read(nonce); err != nil {
		return nil, err
	}
	return gcm.Seal(nonce, nonce, plaintext, nil), nil
}
```

### API focus: gcm.Open

Fail closed on tag mismatch — do not return partial plaintext.

```go
func Decrypt(key, blob []byte) ([]byte, error) {
	block, err := aes.NewCipher(key)
	if err != nil {
		return nil, err
	}
	gcm, err := cipher.NewGCM(block)
	if err != nil {
		return nil, err
	}
	if len(blob) < gcm.NonceSize() {
		return nil, fmt.Errorf("ciphertext too short")
	}
	nonce, ct := blob[:gcm.NonceSize()], blob[gcm.NonceSize():]
	return gcm.Open(nil, nonce, ct, nil)
}
```

### Trace: field-level encryption

```text
1. DataClass = confidential
2. DEK from rand
3. Encrypt field AES-GCM
4. Wrap DEK with KEK (envelope)
5. Store ciphertext + wrapped DEK in DB
6. KEK rotation — re-wrap DEK
```

### API focus: crypto/rand nonce

Never fixed nonce or counter without atomic store — reuse nonce with same key breaks GCM.

### API focus: crypto/hmac

Message integrity / log pseudonym — HMAC-SHA256 with secret key, not plain hash.

```go
func Sign(key, msg []byte) []byte {
	m := hmac.New(sha256.New, key)
	m.Write(msg)
	return m.Sum(nil)
}

func Verify(key, msg, sig []byte) bool {
	return hmac.Equal(Sign(key, msg), sig)
}
```
