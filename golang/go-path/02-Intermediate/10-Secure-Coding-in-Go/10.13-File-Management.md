# 10.13 File Management

> **Go Path - Zero to Gopher** / **02 Intermediate → Secure Coding in Go** / Lesson 10.13

## Lesson goals

After this lesson you should:

- use `filepath.Clean` and **careful checking** that the resolved path stays inside the base directory
- explain the failure mode: user relative segments can leave the intended tree (path traversal) — without exploit strings in the text
- generate server-side file names instead of trusting the client name
- enforce size limits; least privilege on FD (O_RDONLY)
- connect this with confidentiality of files outside the base

## Prerequisite

- 10.03 validation; `path/filepath`, `os`

## Problem this lesson solves

If you join a base dir with untrusted relative input without checking, the resulting path can point to a file *outside* the allowed tree. Impact: read or write of configuration, keys, other users’ uploads. Defense: Clean + prefix/Rel check, server ID, limits.

## Mental model

1. **Base** — the only root of the allowed tree.
2. **Clean** — normalizes `.` and `..` segments.
3. **Confine** — after Join+Clean, confirm the path is still under base.
4. **Server name** — UUID/hash name on disk; original in metadata.
5. **Limit** — MaxBytes upload.

```text
user segment → Clean → Join(base, ...) → Rel/prefix check → Open
```

## Mechanism

### Failure mode (in words)

The user sends a relative path that after normalization leaves the base directory (classic: segments that go “up” in the tree). Without checking, `Open` reads outside intent. **We do not cite payloads;** we show safe join.

### Safe confine

```go
func Confine(base, userPath string) (string, error) {
	base = filepath.Clean(base)
	target := filepath.Clean(filepath.Join(base, userPath))
	rel, err := filepath.Rel(base, target)
	if err != nil {
		return "", err
	}
	if rel == ".." || strings.HasPrefix(rel, ".."+string(os.PathSeparator)) {
		return "", fmt.Errorf("path escapes base")
	}
	return target, nil
}
```

`HasPrefix(base)` on a string alone is not enough (e.g. `base` vs `base2`) — the `Rel` approach is more careful.

### Windows/POSIX

`filepath` respects OS separators. Test on target platform. `filepath.Clean` does not resolve symlink escape alone — for stricter: `EvalSymlinks` + check, or forbid symlink in base.

## Rules

1. Always Confine before Open/Write.
2. Server names for upload.
3. MaxBytes on upload.
4. O_RDONLY when no write.
5. Do not log full paths with secret names unless needed.
6. Test escape attempts (expect error) without public payload tutorials — use `..` in test as data.

## Decision analysis

| Decision | Why |
|--------|-------|
| Rel check | more correct than naive HasPrefix |
| UUID name | client does not choose path |
| MaxBytes | availability |
| Test escape | CI catches regression |

## Trade-offs

- **Symlink policy** complicates.
- **Allow extension** vs UX.
- **EvalSymlinks** race (TOCTOU) — keep base without user symlink.

## Common mistakes

1. Join without confine.
2. Client name as path.
3. HasPrefix string only.
4. No MaxBytes.
5. Writable dir with execute rights without need.
6. Zip extract without confine (related problem).
7. Log full path of secret storage.
8. Believing Clean alone fixes everything.
9. Open before check.
10. Same dir for upload and code.

## Idiomatic Go

- `path/filepath` not `path` for local FS.
- `t.TempDir` in tests.
- Small `filesafe` package.

### API focus: filepath.Rel confine

Verify the resulting path stays inside root.

```go
func Confine(root, rel string) (string, error) {
	root = filepath.Clean(root)
	abs := filepath.Join(root, filepath.Clean(rel))
	relOut, err := filepath.Rel(root, abs)
	if err != nil {
		return "", err
	}
	if strings.HasPrefix(relOut, "..") {
		return "", fmt.Errorf("path escapes root")
	}
	return abs, nil
}
```

### API focus: symlink policy

```go
func openAfterEval(root, rel string) (*os.File, error) {
	abs, err := Confine(root, rel)
	if err != nil {
		return nil, err
	}
	fi, err := os.Lstat(abs)
	if err != nil {
		return nil, err
	}
	if fi.Mode()&os.ModeSymlink != 0 {
		return nil, fmt.Errorf("symlinks not allowed")
	}
	return os.OpenFile(abs, os.O_RDONLY, 0)
}
```

### API focus: http.FileServer forbidden

Do not expose the whole disk — serve files through a handler that maps ID → path from DB + Confine.

```go
func (h *Handler) Download(w http.ResponseWriter, r *http.Request) {
	id, err := parseUUIDField("id", r.PathValue("id"))
	if err != nil {
		http.Error(w, "bad request", 400)
		return
	}
	meta, err := h.repo.FileMeta(r.Context(), id, PrincipalFromMust(r.Context()))
	if err != nil {
		http.Error(w, "not found", 404)
		return
	}
	path, err := Confine(h.root, meta.RelPath)
	if err != nil {
		WriteInternal(w)
		return
	}
	http.ServeFile(w, r, path)
}
```
