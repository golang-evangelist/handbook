# 10.10 Communication Security

> **Go Path - Zero to Gopher** / **02 Intermediate → Secure Coding in Go** / Lesson 10.10

## Lesson goals

After this lesson you should:

- require **at least TLS 1.2** in the `crypto/tls` configuration
- understand certificate verification on the client (not `InsecureSkipVerify` in production)
- set timeouts on `http.Client` and `http.Server`
- document the assumption of TLS termination at the proxy
- connect TLS with confidentiality and integrity in transit

## Prerequisite

- 10.08–10.09; basic HTTPS concepts
- `crypto/tls`, `net/http`

## Problem this lesson solves

Plain HTTP and old TLS protocols expose or weaken traffic. In Go the defaults are solid, but explicit `MinVersion`, timeouts, and forbidding skip-verify make production policy visible in code.

## Mental model

1. **TLS** — encryption + peer authentication via certificates.
2. **MinVersion TLS 1.2** — reject older versions.
3. **Chain of trust** — the client verifies the server cert (CA).
4. **Timeout** — availability.
5. **Terminate at proxy** — an assumption; app↔proxy you still control.

## Mechanism

### Server MinVersion

```go
cfg := &tls.Config{MinVersion: tls.VersionTLS12}
srv := &http.Server{Addr: ":443", Handler: mux, TLSConfig: cfg, ReadHeaderTimeout: 5 * time.Second}
```

### Client

```go
tr := &http.Transport{TLSClientConfig: &tls.Config{MinVersion: tls.VersionTLS12}}
client := &http.Client{Timeout: 20 * time.Second, Transport: tr}
```

### InsecureSkipVerify

`InsecureSkipVerify: true` disables name/CA verification — lab only with conscious risk, never production. Impact: MITM can impersonate the peer.

### Predict, then check (1)

```go
tls.Config{InsecureSkipVerify: true} // "temporary in staging"
```

<details>
<summary>Answer</summary>

Staging with production data → same risk. Use a real cert (e.g. internal CA).

</details>

### Predict, then check (2)

No client Timeout.

<details>
<summary>Answer</summary>

Goroutine/connection hangs — availability.

</details>

### mTLS (concept)

Both peers present a cert — for service-to-service. Configure `Certificates` + `ClientAuth` on the server. Ops issues certs; code only loads them.

### HTTPS boot trace

```text
Load cert/key files → tls.Config MinVersion → ListenAndServeTLS
or: plain Listen behind proxy + ADR assumption
```

## Rules

1. MinVersion ≥ TLS 1.2.
2. No InsecureSkipVerify in prod.
3. Client and Server timeouts.
4. Document TLS termination.
5. Certs outside git (file mount / secret).
6. HSTS at the edge per ops policy (brief mention).

## Examples

### Example 1 — Server TLS 1.2+

```go
func NewServer(mux http.Handler, addr string) *http.Server {
	return &http.Server{
		Addr:              addr,
		Handler:           mux,
		ReadHeaderTimeout: 5 * time.Second,
		ReadTimeout:       15 * time.Second,
		WriteTimeout:      30 * time.Second,
		IdleTimeout:       60 * time.Second,
		TLSConfig:         &tls.Config{MinVersion: tls.VersionTLS12},
	}
}
```

#### What happens here

Explicit version + timeouts.

### Example 2 — Client

```go
func ClientTLS12() *http.Client {
	return &http.Client{
		Timeout: 20 * time.Second,
		Transport: &http.Transport{
			TLSClientConfig:   &tls.Config{MinVersion: tls.VersionTLS12},
			ForceAttemptHTTP2: true,
		},
	}
}
```

#### What happens here

The client does not accept older TLS; it has an overall Timeout.

### Example 3 — loading a pair

```go
cert, err := tls.LoadX509KeyPair("server.crt", "server.key")
cfg := &tls.Config{Certificates: []tls.Certificate{cert}, MinVersion: tls.VersionTLS12}
```

#### What happens here

Stdlib loading; files from secret mount, not from the repo.

## Decision analysis

| Decision | Why |
|--------|-------|
| TLS 1.2 min | reject weak protocols |
| Timeout | availability |
| No skip verify | peer integrity |
| ADR for proxy | clear trust boundary |

## Trade-offs

- **Old clients** below 1.2 — you consciously break them or keep a legacy endpoint.
- **mTLS** is operationally harder.
- **HTTP/2** performance, not a substitute for verification.

## Common mistakes

1. InsecureSkipVerify in prod.
2. No MinVersion (relying on memory).
3. No timeout.
4. Cert in git.
5. Mixing proxy assumption and app TLS.
6. Plain HTTP admin API “internal network”.
7. Infinite redirect loop HSTS misconfig (ops).
8. Sharing one cert everywhere without inventory.
9. Ignoring cert expiry (monitoring).
10. Custom “encrypt body” instead of TLS.

## Idiomatic Go

- `&tls.Config{MinVersion: tls.VersionTLS12}` explicitly.
- `http.Client{Timeout: ...}` always.
- Test that staging uses the same TLS policies where needed.

## Practical scenario

A service calls payment with skip verify “because lab cert”. Staging leaks. The team introduces internal CA, MinVersion, Timeout, removes skip. ADR: edge terminate + mTLS to payment.

### ALPN and HTTP/2

`tls.Config` with `NextProtos` defines ALPN. If the service listens for HTTP/2, document cipher suite policy and whether `h2` is used only behind TLS.

### API focus: tls.Config MinVersion

Client and server must enforce TLS 1.2+ (1.3 recommended). Old protocols fail at handshake.

```go
tlsConfig := &tls.Config{
	MinVersion: tls.VersionTLS12,
}
```

### API focus: http.Transport TLS

Outbound calls use a custom `Transport` with `TLSClientConfig` — not default if you need pinning or mTLS.

```go
tr := &http.Transport{
	TLSClientConfig: &tls.Config{
		MinVersion: tls.VersionTLS12,
		RootCAs:    pool,
	},
}
client := &http.Client{Transport: tr, Timeout: 10 * time.Second}
```

### Example: pinned webhook client

```go
func webhookClient(ca []byte) (*http.Client, error) {
	pool := x509.NewCertPool()
	if !pool.AppendCertsFromPEM(ca) {
		return nil, fmt.Errorf("bad ca")
	}
	tr := &http.Transport{
		TLSClientConfig: &tls.Config{
			MinVersion: tls.VersionTLS12,
			RootCAs:    pool,
		},
	}
	return &http.Client{Transport: tr, Timeout: 10 * time.Second}, nil
}
```

### API focus: TLS listen hardening

```go
srv := &http.Server{
	Addr:         ":443",
	Handler:      mux,
	TLSConfig:    srvTLS,
	ReadTimeout:  30 * time.Second,
	WriteTimeout: 30 * time.Second,
}
if err := srv.ListenAndServeTLS("fullchain.pem", "key.pem"); err != nil {
	slog.Error("tls serve", "err", err)
}
```

Timeouts on the TLS server are an availability control — they do not replace `MinVersion` or verify.
