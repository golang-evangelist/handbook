# 10.09 Data Protection

> **Go Path - Zero to Gopher** / **02 Intermediate → Secure Coding in Go** / Lesson 10.09

## Lesson goals

After this lesson you should:

- classify data (public / internal / PII / secret / payment) and tie controls
- reduce surface: do not collect data you do not need
- separate **in transit** (TLS) and **at rest** (AES-GCM / disk encryption ops)
- separate keys; mask PII in logs
- connect least privilege with access to dumps and backups

## Prerequisite

- 10.01, 10.08; basic slog

## Problem this lesson solves

Teams often “have TLS” and think data is protected. Backup, log, CSV export and debug endpoint still carry PII. Data protection is policy + Go decisions: what you store, where, who reads, how you mask.

## Mental model

1. **Minimization** — do not ask for national ID if you only need hash for dedup.
2. **Classification** — picks controls (10.01 catalog).
3. **In transit** — TLS.
4. **At rest** — AEAD fields / volume encryption (ops).
5. **Masking** — log and support UI.
6. **Retention** — delete when policy says.

## Mechanism

### Classification → controls

| Class | Example control |
|-------|-----------------|
| public | cache OK |
| PII | authz, TLS, mask log, AEAD optional |
| secret | env/store, never log |
| payment | strict authz, audit, short retention |

### Masking

```go
func MaskEmail(s string) string {
	at := strings.LastIndex(s, "@")
	if at <= 1 {
		return "***"
	}
	return s[:1] + "***" + s[at:]
}
```

Not “sanitize attack” — reduce PII in log.

### Export and derivatives

CSV export, BI replica, search — same class as source. Least privilege account for export job.

### Backup

## Rules

1. Do not collect excess PII.
2. Classify before feature.
3. TLS in transit; at-rest per class.
4. Mask in log/UI.
5. Separate keys (10.08).
6. Retention and deletion per policy.
7. Export job = same authz spirit.

## Decision analysis

| Decision | Why |
|--------|-------|
| Minimization | smaller blast radius |
| Mask log | operational confidentiality |
| AEAD selective | costlier; for high class |
| DTO projection | model does not leak |

## Trade-offs

- **More encryption** = harder search/index.
- **Masking** harder support debug — balance + break-glass audit.
- **Short retention** vs forensics.

## Common mistakes

1. Full objects in log.
2. Export without authz.
3. “We have TLS” as only control.
4. Same key for everything.
5. Infinite PII retention.
6. Debug endpoint with raw row.
7. BI replica with production secrets.
8. Backup publicly readable.
9. Mixing public DTO and admin DTO.
10. Forgotten derivatives (search index).

## Idiomatic Go

- Separate DTO per class.
- `slog` attribute allow-list.
- Test that public JSON does not contain email.

## Practical scenario

Support logs entire User. GDPR request → masking, 30-day retention, AEAD for one sensitive attribute, separate export account.

### Retention and deletion (GDPR operationally)

Retention policy is not legal text in vacuum — implement with job with `context` deadline and audit log who started purge. Least privilege: purge job service account may only DELETE on PII tables, not whole DROP.

### Pseudonymization for analytics

Instead of raw email in analytics event, send HMAC pseudonym with server-only pepper from env. Confidentiality: analytics team does not see PII; you can still count unique users.

### API focus: DataClass enum

Classification determines which log, export and encryption apply — without classification you treat everything as public.

```go
type DataClass int

const (
	DataPublic DataClass = iota
	DataInternal
	DataConfidential
	DataRestricted
)

func (c DataClass) RequiresFieldEncrypt() bool {
	return c >= DataConfidential
}
```

### API focus: HMAC pseudonym log

Analytics ID = HMAC(userID) — reversibility only with key in secure store.

```go
func PseudonymID(key []byte, userID string) string {
	m := hmac.New(sha256.New, key)
	m.Write([]byte(userID))
	return hex.EncodeToString(m.Sum(nil))[:16]
}
```

### API focus: analytics pseudonym rotation

Rotate HMAC key for pseudonyms periodically; old key only for join in transition period.

```go
func Pseudonym(keyID string, userID string, keys map[string][]byte) (string, error) {
	key, ok := keys[keyID]
	if !ok {
		return "", fmt.Errorf("unknown key id")
	}
	m := hmac.New(sha256.New, key)
	m.Write([]byte(userID))
	return hex.EncodeToString(m.Sum(nil))[:16], nil
}
```
